**Leonida Legend** — an offline guide and tracker for all 55 PlayStation 5 trophies of Grand Theft Auto VI. Every trophy carries its official name, description and grade, an original guide in our own words, and the sources that guide is built from. It includes a four-stage roadmap to the platinum, flags the list's one missable trophy (Positive Mental Attitude, a point of no return in Chapter 1), kind and grade filters with search, a spoiler-safe mode that masks unearned story trophies, and a checklist whose progress is saved in the browser and can be exported to a file and imported back. The app is plain static files under `app/` and runs fully offline.

## Run it

```sh
node serve.ts
# then open http://localhost:8080 — or hand the entry in with:
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```
