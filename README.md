**Leonida Legend is an offline guide and tracker for all 55 PlayStation 5 trophies of Grand Theft Auto VI. Every trophy is listed with its official name, description and grade, an original guide written in our own words, and the sources that guide rests on. A four-stage roadmap walks you to the platinum, the list's one missable trophy is flagged wherever it appears, and kind filters, a grade filter and text search keep the full list easy to work through. A spoiler-safe mode masks unearned story trophies until you earn them, and your progress is saved in the browser, with export and import, so the checklist survives between sessions. The app is plain static files under `app/` and runs fully offline.**

## Run it

```sh
node serve.ts
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```
